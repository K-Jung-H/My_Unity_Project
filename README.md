1\. 적 잔해 추락 및 소실 (Falling Wreckage)

* 현상: 플레이어가 적 처치 후 해당 지역을 이탈했다가 되돌아오면, 적 잔해가 사라지거나 땅 밑으로 떨어져 있음.
* 예상 원인: 사망한 적(잔해)이 청크의 자식으로 입양되지 않음. 청크가 풀링되어 비활성화(위치 이동)될 때, 잔해만 허공에 남아 중력을 받아 추락함.



2\. 청크 생성 불일치 (Map Mutation)

* 현상: 거리로 인해 비활성화된 지역을 다시 방문하면, 같은 좌표임에도 다른 종류의 청크가 생성됨. 

&nbsp;	- Props를 파괴한 청크인 경우 다른 종류의 청크 생성됨 <-->  Props를 파괴하지 않았을 때는 정상

* 예상 원인: 맵 생성 로직의 결정론 깨짐. // 시드 값 훼손
